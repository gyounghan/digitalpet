# PocketFriend — 앱 기능 소개

> 이 문서는 PocketFriend 앱의 기능과 구조를 외부(AI 어시스턴트 등)에 설명하기 위한 자기완결형 소개 문서입니다. 수치·조건은 실제 코드 기준입니다.

## 한 줄 소개

**PocketFriend**는 사용자의 실제 건강 활동(걸음 수, 수면, 폰 미사용 시간)이 가상 펫의 상태·성장에 반영되는 **다마고치 스타일 건강 습관 앱**입니다. Flutter로 제작되었으며, 걸으면 펫이 행복해지고, 폰을 내려놓으면 펫이 쉬고, 규칙적으로 돌보면 사신수(주작·청룡·백호·현무)로 진화합니다.

## 기술 스택

| 구분 | 내용 |
|---|---|
| 앱 | Flutter (Dart), Clean Architecture (domain / data / presentation) |
| 상태 관리 | Riverpod |
| 로컬 저장 | Hive (NoSQL) |
| 건강 데이터 | Health Connect(Android) / HealthKit(iOS) + 내장 걸음 센서 병행 |
| 백그라운드 | WorkManager (15분 주기) |
| 서버 | NestJS + TypeORM + better-sqlite3 + Socket.IO (펫 동기화·온라인 배틀·랭킹) |
| 홈 위젯 | Android AppWidget (Kotlin 네이티브) |
| 그래픽 | 이미지 파일 없이 도트 좌표 데이터를 CustomPainter로 찍는 픽셀 렌더링 (다마고치 LCD 감성) |

## 1. 펫 스탯과 기분

펫은 3개 스탯을 가집니다 (각 0~100, 100이 최상):

- **포만감(hunger)** — 밥을 먹으면 상승
- **행복(happiness)** — 걸음·운동으로 상승
- **기력(stamina)** — 수면·폰 미사용으로 상승

스탯 조합으로 **기분(mood)** 이 자동 판정됩니다 (우선순위 순):

1. 사망 상태 → `dead`
2. 포만감 ≤ 25 → `hungry` (배고픔 최우선 경고)
3. 기력 ≤ 25 → `tired`
4. 밤(22~06시)에 기력 ≤ 60, 또는 낮에 기력 ≤ 40 → `sleepy`
5. 행복 ≤ 35 → `sad`
6. 포만감 ≥ 75 & 행복 ≥ 70 & 기력 ≥ 60 → `happy`
7. 그 외 → `normal`

기분에 따라 펫의 도트 애니메이션과 대사가 달라지며, 홈 화면·안드로이드 위젯이 동일한 임계값을 공유합니다.

### 스탯 자연 감소 (감쇠)

- 포만감: 60분마다 -2 (밤에는 -1)
- 행복: 60분마다 -1 (밤에는 중단)
- 기력: 40분마다 -1 (밤에는 중단)
- 절대 시각 그리드 방식이라 앱을 껐다 켜도 잔여 시간이 유실되지 않음
- 위기 가속: 스탯 2개 이상이 20 이하이면 감쇠 ×1.5, 10 이하이면 ×2
- 종(種)별 감쇠 배율과 일일 이벤트(감쇠 절반)가 곱해짐

### 사망과 부활

- 세 스탯이 **모두 0인 상태가 5일 연속** 지속되면 펫이 사망
- 부활(광고 시청): 1회차 스탯 50 복구, 2회차 40, 3회차부터는 30 복구 + **레벨 -1 패널티**

## 2. 건강 데이터 연동 (핵심 차별점)

| 실제 활동 | 측정 방법 | 펫에 미치는 효과 |
|---|---|---|
| 걸음 수 | Health Connect/HealthKit + 내장 센서 중 큰 값 | 1,000보당 행복 +3, 5,000보 달성 +10, 10,000보 추가 +15 |
| 운동 시간 | 헬스 WORKOUT 레코드 | 10분당 행복 +5, 15분 +8, 30분 추가 +12 |
| 폰 미사용 | 마지막 포그라운드 시각 기준 (10분 임계) | 10분당 기력 +1 → "수면 시간"으로 누적 |

- 증가분(delta) 방식으로 중복 반영을 방지하고, 앱을 오래 안 열었어도 열 때 과거 데이터를 소급 반영(catch-up)합니다.
- 즉 "폰을 덜 보고 많이 걷기"가 게임의 핵심 루프입니다.

## 3. 레벨·경험치

- 레벨업 필요 EXP 곡선: Lv1~3 구간 50 → 100 → 200 → 350 → 550 → 800 → Lv28+ 1100 (완만한 증가, 약 170일에 Lv30 페이스)
- 레벨업 시 세 스탯 각 +10 보너스
- EXP 획득 경로: 밥주기 +5, 접속 보너스 +3(하루 3회), 연속 접속 보상 +10/+25/+50/+100, 일일 목표 달성 +20, 세트 보상(아래), 배틀 승리 50/압승 70/패배 15

---

## 4. 일일 목표 (카테고리 목표)

레벨에 따라 커지는 3개 카테고리 목표가 매일 주어집니다:

| 카테고리 | 목표치 (레벨 구간별) |
|---|---|
| 식사 | 1회 (Lv≤5) → 2회 (Lv≤15) → 3회 |
| 수면 | 5시간 (Lv≤10) → 6시간 (Lv≤20) → 7시간 |
| 걸음 | 3,000 → 4,000 → 5,000 → 6,000 → 8,000보 |

- 카테고리 1회 달성마다 EXP +20, **하루 카테고리당 최대 3회**까지 지급 (초과 진행분은 다음 날로 이월)
- 3개 카테고리를 모두 달성하면 **세트 보상**: 첫 세트 60 EXP, 이후 세트마다 반감 (60 → 30 → 15 → …)
- 카테고리 10회 누적 / 세트 10개 누적 마일스톤마다 티어업 보너스 +50 EXP
- 홈 화면 "오늘의 목표" 카드에 3개 진행바 + 세트 진행이 표시됨

## 5. 일일 이벤트

매일 첫 접속 시 하나가 추첨됩니다:

| 이벤트 | 효과 | 확률 |
|---|---|---|
| 맑은 날 (sunny) | 걸음 행복 보상 ×1.5 | 20% |
| 포근한 날 (cozy) | 수면 기력 회복 ×1.5 | 20% |
| 맛있는 날 (tasty) | 식사 시 포만감 +5 추가 | 20% |
| 행복한 날 (happy_day) | 스탯 감쇠 ×0.5 | 10% |
| 모험의 날 (adventure) | 배틀 EXP ×2 | 15% |
| 평범한 날 | 효과 없음 | 15% |

## 6. 케어 행동 (직접 돌보기)

| 행동 | 효과 | 일일 제한 |
|---|---|---|
| 밥주기 | 포만감 +20, EXP +5 | 아침(6:30~10)/점심(11~14:30)/저녁(17~21) 슬롯당 1회 |
| 재우기 | 기력 +10 | 3회 |
| 대체 급식 (간식) | 포만감 +8 | 3회 (시간대 무관, 저효율) |
| 대체 수면 (휴식) | 기력 +6 | 4회 |
| 흔들기 (실내 운동) | 흔들기 1회 = 5걸음 환산 (세션 최대 100회) | 1회 |
| 자동 급식 | 포만감 < 30이면 식사 시간대에 자동 +30 (위급 시 시간대 무관) | 3회 |

모든 회복량에 종별 성장 배율이 적용됩니다.

## 7. 진화 시스템 (사신수)

펫은 4단계로 진화합니다: **털뭉치 → 유아기(Lv5) → 성장기(Lv10) → 성숙기(Lv15)**

### 종 결정 (Lv5, 유저 생활 패턴 기반)

두 축의 누적 활동을 비교해 4종 중 하나로 분기:

- **활발 ↔ 차분** 축: 걸음·운동 vs 수면·폰 미사용
- **규칙 ↔ 자유** 축: 연속 접속일 vs 식사 달성 횟수

| | 규칙적 | 자유로움 |
|---|---|---|
| **활발** | 백호 (tiger) | 주작 (bird) |
| **차분** | 현무 (turtle) | 청룡 (snake) |

미션 완료가 축 점수에 가산되어 원하는 종으로 유도할 수 있습니다.

### 등급 분기

- **성장기(Lv10)**: 종에 해당하는 두 축의 누적 카운터(예: 운동 달성 ≥15회, 연속 접속 ≥12일)를 모두 채우면 **superior**, 아니면 normal
- **성숙기(Lv15)**: superior 상태에서 더 높은 임계(≥40회 / ≥25일)를 채우면 **사신수(mythical)**, 아니면 일반종
- 종별로 성장 배율이 다름 (예: 주작은 행복 획득 ×1.3, 백호는 EXP ×1.3, 현무는 기력 회복 ×1.2)

## 8. 배틀 시스템

### 전투 스탯 (펫의 성장이 그대로 반영)

- **ATK** = (5 + 레벨 + 누적 세트 보너스 + 진화 단계 보너스 + 종 보너스) × 행복 컨디션 보정(±20%)
- **DEF** = 같은 base × 기력 보정(±20%)
- **HP** = (50 + 레벨×2 + 누적 걸음 보너스 + 종 보너스) × 포만감 보정(±20%)

→ 평소에 잘 돌보고 많이 걸을수록 강해집니다.

### 규칙

- 하루 3회, 최대 7턴 자동 시뮬레이션
- **배틀 스타일** 선택: 공격형(ATK×1.2/DEF×0.9) / 균형형 / 방어형(DEF×1.2/ATK×0.9)
- **상성**: 주작→청룡→현무→백호→주작 (유리하면 데미지 ×1.2, 불리 페널티는 없음)
- **종별 스킬**: 기본기 + 특수기(쿨다운 2턴) — 주작 급강하(데미지 ×1.5), 청룡 조이기(적 DEF-3), 백호 포효(적 ATK-3), 현무 방어자세(받는 피해 -50%)
- **보상**: 승리 50 / 압승 70 / 패배 15 EXP, 하루 1·2·3번째 배틀에 ×1.0/×0.7/×0.5 배수, 모험의 날 ×2

### 온라인 PvP

- Socket.IO 실시간 매칭 (`battle:join` → 매칭 → 서버 시뮬레이션 → `battle:result`)
- 서버는 승패·기본 EXP만 판정하고, 실제 보상 적용은 클라이언트가 AI 배틀과 동일한 로직으로 처리
- 상대가 이탈하면 승리 처리

## 9. 랭킹

- 서버 REST API: TOP3 + 내 순위 주변 5명 + 전체 인원 수 표시
- 랭킹 점수(RP)는 서버가 산정하며, 온라인 배틀 결과로 갱신
- 오프라인이면 폴백 배너 표시 (앱은 서버 없이도 완전 동작 — 로컬 우선 설계)

## 10. 그 외 기능

- **안드로이드 홈 위젯**: 펫 도트 + 레벨 + 기분을 홈 화면에 표시, 800ms 주기 프레임 애니메이션. 앱과 동일한 도트 데이터·기분 판정 로직을 Kotlin 네이티브가 공유
- **백그라운드 처리**: WorkManager 15분 주기로 감쇠 → 사망 체크 → 자동 수면 → 알림 → 자동 급식 → 활동 동기화 → 목표 적용 → 진화 → 위젯 갱신 파이프라인 실행
- **알림**: 하루 최대 3회, 우선순위 = 배고픔(< 30) > 행복 낮음(< 30) > 6시간 미접속. 식사 시간대(8시/13시/19시) 리마인더 별도
- **기기 이전**: 이전 코드 발급 → 새 기기에서 입력해 펫 이전 (서버 API)
- **펫 동기화**: `lastUpdated` 타임스탬프 비교로 서버·로컬 중 최신 데이터 채택 (오프라인 내성)
- **도트 렌더링**: 이미지 에셋 없이 오프라인 생성된 도트 좌표 데이터를 CustomPainter로 찍음. 3계조(아웃라인/몸통=종별 테마색/보조색), 기분·행동별 모션 프레임

## 12. 설계 특징 (개발 관점)

- **Clean Architecture**: domain(순수 Dart 엔티티·유스케이스 ~20개) ← data(Hive/Health/서버 구현) → presentation(Riverpod). 모든 비즈니스 로직은 UseCase로만 진입
- **3자 일치 원칙**: 기분 판정·도트 렌더링 로직이 Flutter 앱, Android 네이티브 위젯, 서버에서 일치하도록 유지
- **오프라인 우선**: 서버 없이 전 기능 동작(온라인 배틀·랭킹 제외), 서버 호출 실패는 조용히 폴백
- **중복 반영 방지**: 건강 데이터는 delta 기반 + 소급(catch-up) 반영, 배틀/목표 보상은 워터마크(카운터) 기반 신규분만 지급
