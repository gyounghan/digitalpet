# Previous UI Mock Archive

이 폴더는 이전 디자인 시안을 Claude Code가 바로 볼 수 있도록 저장한 참고용 아카이브입니다.

## 열어볼 파일

- `index.html`: 브라우저에서 볼 수 있는 이전 디자인 시안 안내 페이지
- `previous-design.png`: 이전 디자인 시안 전체 스크린샷
- `pet-*.png`: 시안에 사용된 펫 이미지 리소스

## 중요한 주의사항

이 시안은 사용자가 "컨셉은 좋다"고 한 이전 버전 디자인입니다. 하지만 현재 앱 코드에 없는 기능 UI가 포함되어 있으므로, 그대로 구현하면 안 됩니다.

현재 없는 기능으로 확인된 요소:

- 홈 화면의 `놀기`, `휴식` 액션
- 배틀 화면의 `기본 공격`, `스킬`, `방어`, `응원` 같은 수동 전투 선택 버튼
- 전체 펫 도감 그리드처럼 현재 코드 기능보다 넓게 보이는 수집형 UI

이 디자인을 참고할 때는 분위기, 배치 밀도, 펫을 크게 보여주는 방식, 더 귀여운 육성감만 가져오고, 실제 구현은 현재 코드에 존재하는 기능만 사용해야 합니다.

## 현재 기능 기준으로 유지해야 할 방향

- 홈: 현재 펫, 레벨, 경험치, 밥주기, 오늘 목표 중심
- 케어: 상태, 집중 모드, 물마시기, 간편 급식, 낮잠 모드, 흔들기 보너스, 미션 중심
- 배틀: 전투 스타일, AI 대전, 친구 방 만들기, 코드로 참가, 남은 횟수, 최근 전투 기록 중심
- 도감/내 정보: 현재 펫 프로필, 전투 스탯, 누적 기록, 진화 트리, 계정/재시작 관련 기능 중심

## 의도

사용자가 원한 방향은 "AI가 만든 느낌"을 줄이고, 펫이 잘 보이며, 진짜 키우는 귀여운 펫 앱처럼 느껴지게 하는 것입니다.
